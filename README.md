# Smart Request Chain

4-этапная LangChain-цепочка для обработки обращений в службу поддержки:

1. **Анализ** — категория, приоритет, сущности, риски
2. **Подбор инструментов** — план действий и эскалация
3. **Черновик ответа** — текст для клиента
4. **Ревью** — проверка качества и финальная версия

Запросы к LLM идут через [ProxyAPI](https://proxyapi.ru) — OpenAI-совместимый API без VPN.

## Требования

- Python 3.10+
- Аккаунт и API-ключ на [ProxyAPI](https://console.proxyapi.ru/keys)

## Установка

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate

pip install -r requirements.txt
```

## Настройка

Скопируйте пример конфигурации и укажите свой ключ:

```bash
# Windows
copy .env.example .env

# Linux / macOS
cp .env.example .env
```

Заполните `.env`:

| Переменная | Описание |
|------------|----------|
| `PROXYAPI_KEY` | API-ключ ProxyAPI (также принимается `OPENAI_API_KEY`) |
| `OPENAI_BASE_URL` | Базовый URL (по умолчанию `https://openai.api.proxyapi.ru/v1`) |
| `MODEL_NAME` | Модель в формате `провайдер/модель`, например `openai/gpt-4o-mini` |
| `TEMPERATURE` | Температура генерации (по умолчанию `0.2`) |

Примеры моделей для универсального API:

- `openai/gpt-4o-mini`
- `openai/gpt-4o`
- `anthropic/claude-sonnet-4-20250514`

Список моделей: [документация ProxyAPI](https://proxyapi.ru/docs/openai-compatible-api).

## Запуск

```bash
python main.py
```

Программа запросит текст обращения (можно вводить несколько строк; для завершения — Enter на пустой строке). В консоли отображается прогресс по 4 этапам, в лог — время выполнения каждого шага.

## Как это работает

```
Обращение → Анализ → Инструменты → Черновик → Ревью → Финальный ответ
```

Этапы выполняются последовательно в `process_request()`. На шагах 1, 2 и 4 используется structured output (Pydantic), на шаге 3 — текстовый ответ. В консоль выводится прогресс и краткие итоги каждого этапа, в лог — время выполнения.
